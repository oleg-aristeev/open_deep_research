# Гайдлайн ручной разметки claim-level (v0)

Цель: разметить пары (клейм, цитата) и вердикты системы. Первые 30 клеймов
размечают оба инженера независимо; считаем каппу Коэна (κ). Если κ < 0.6 —
чиним гайдлайн до продолжения разметки (MVP plan §6.3).

## Что показывается

Для каждого клейма: текст клейма, вердикт системы (supported / refuted /
disputed / not_enough_evidence), цитата-свидетельство, подсвеченный фрагмент
снапшота страницы.

## Вопросы и правила ответа

### 1. Поддерживает ли цитата клейм? (supports / refutes / qualifies / mentions)

- **supports** — если цитата правдива, клейм становится вероятнее. Цитата не
  обязана дословно повторять клейм, но должна покрывать его суть: субъект,
  значение, период.
- **refutes** — цитата прямо противоречит клейму (другое значение той же
  величины при той же методике; «не X» против «X»).
- **qualifies** — цитата сужает клейм: «верно, но только при B», «верно для
  подгруппы», «другая методика даёт другое число». Если сомневаетесь между
  refutes и qualifies: refutes — это «клейм неверен», qualifies — «клейм
  верен не безусловно».
- **mentions** — тема та же, сигнала нет. Если нужно «додумать» связь — это
  mentions.

Правило честности: судим только по цитате, не по своим знаниям. Если цитата
не видна в снапшоте (подсветка не нашлась) — ставим `quote_not_found`.

### 2. Верен ли вердикт системы? (да / нет / частично)

- «да» — вердикт совпадает с вашей оценкой по всем показанным свидетельствам.
- «частично» — направление верное, но флаги/уверенность неадекватны
  (например, supported без qualifier при явных оговорках в свидетельствах).
- «нет» — направление неверное.

### 3. Верен ли scope клейма? (да / нет)

«Нет», если при деконтекстуализации потерян/искажён субъект, период, единицы,
методика — т.е. проверяется не то утверждение, что было в источнике.

## Частые ловушки

- Относительный vs абсолютный риск/рост — это qualifies, не supports.
- Перепечатка того же пресс-релиза — supports, но пометьте подозрение на
  circular в комментарии.
- Прогнозы и мнения не бывают supported/refuted — только качество атрибуции.
- Не наказывайте систему за «слишком осторожно» в вопросе 1; это вопрос 2.

## Процедура

1. `streamlit run evals/annotate/app.py -- --run-dir .verify_store/runs/<run_id>`
2. Ответы сохраняются в `evals/annotate/labels.csv` (append-only).
3. Спорные кейсы — в столбец `comment`, разбираем на еженедельном разборе.
